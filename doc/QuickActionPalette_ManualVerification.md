# Quick Action Palette 수동 검증 체크리스트

## 0. 문서 목적

`doc/ActionEngine_QuickActionPalette_Design.md` §19 Manual과 §21 Release Gate 중 **자동 테스트로 대체할 수 없는 항목**을 기록하기 위한 문서다.

자동 검증은 이미 통과했다.

```text
build            경고 0 / 오류 0
automated test   176 통과 / 0 실패 / 0 건너뜀
git diff --check PASS
publish          self-contained 단일 파일 생성, 버전 일치
```

아래 항목은 **하나도 수행되지 않았다.** 전부 `판정 불가` 상태이며, 이 문서가 채워지기 전에는 release 가능으로 판정하지 않는다.

기록 규칙:

- `PASS` / `FAIL` / `판정 불가`만 사용한다.
- `FAIL`은 재현 절차와 관찰된 동작을 함께 적는다.
- 실행하지 못한 항목을 비워 두지 말고 `판정 불가`와 이유를 적는다.

검증 환경을 먼저 기록한다.

| 항목 | 값 |
|---|---|
| 빌드 | `1.2.0+42821ab` |
| Windows 버전 | |
| 검증자 / 날짜 | |
| 기본 설정 여부 | 클립보드 우선 / UIA 우선 |

## 1. 보안 — 최우선

probe #1/#2가 실제로 `Ctrl+C`를 막는지 확인한다. 이 절이 `PASS`가 아니면 release하지 않는다.

| # | 절차 | 기대 | 결과 | 비고 |
|---|---|---|---|---|
| S1 | Windows 자격 증명 UI(예: `runas`, UAC 자격 증명 입력)에서 비밀번호 칸에 커서를 두고 `Alt+R` | "보호된 입력 영역에서는 사용할 수 없습니다." 표시, 클립보드 내용 불변, Gemini 호출 없음 | | |
| S2 | 메모장에 임의 문자열을 복사해 클립보드를 채운다 → S1 반복 → 클립보드 확인 | 원래 문자열이 그대로 남아 있음 | | |
| S3 | Chrome 로그인 폼에서 **아이디 칸** 선택 → `Alt+R` | 정상 번역 | | |
| S4 | **S3와 같은 창에서** 아이디를 선택한 뒤 `Ctrl+Alt+A`를 누르고, 팔레트가 뜨기 전에 Tab으로 비밀번호 칸으로 이동 | 비밀번호 칸으로 `Ctrl+C`가 가지 않음 | | probe #2의 핵심 근거 |
| S5 | Edge에서 S3~S4 반복 | 동일 | | |
| S6 | Electron 앱(Slack/VS Code 등) 입력란에서 S3~S4 반복 | 동일 | | |
| S7 | UIA를 지원하지 않는 앱에서 `Alt+R` | 기존 Clipboard-first 동작 유지(`Unknown`이 차단하지 않음) | | |
| S8 | 관리자 권한으로 실행한 앱을 대상으로 `Alt+T` | 자동 입력 차단 안내 | | |

> S4는 타이밍이 짧아 재현이 어려울 수 있다. 재현되지 않으면 `판정 불가`로 적고, 재현 시도 횟수를 함께 남긴다.

## 2. Quick Action Palette

| # | 절차 | 기대 | 결과 | 비고 |

| P11 | 보조 모니터, 특히 **음수 좌표** 모니터에서 P1 | 작업 영역 안에 표시 | | |

probe 도입으로 기존 경로가 느려지거나 실패하지 않는지 확인한다.

| # | 절차 | 기대 | 결과 | 비고 |

## 4. 단축키 등록

| # | 절차 | 기대 | 결과 | 비고 |
|---|---|---|---|---|
| H1 | 다른 앱이 `Ctrl+Alt+A`를 선점한 상태로 시작 | Palette만 비활성, **`Alt+R`/`Alt+T`는 정상 동작**, 경고 1회 | | |
| H2 | 다른 앱이 `Alt+T`를 선점한 상태로 시작 | `Alt+R`은 정상 동작, 실패한 단축키만 경고 | | |

## 6. 실제 Gemini 응답 품질 (Gate 3)

network 호출이 필요하므로 자동 테스트로 대체할 수 없다. 각 20회 실행 후 비율을 기록한다.

| # | 항목 | 기준 | 결과 |
|---|---|---|---|
| G1 | `자연스럽게 다듬기`가 원문 **언어를 유지** | | /20 |
| G2 | `자연스럽게 다듬기`가 의미·어조를 유지 | | /20 |
| G3 | `요약`이 원문 **언어로** 출력 | | /20 |
| G4 | 설명·라벨·코드펜스가 섞이지 않음 | | /20 |
| G5 | 내부 `WTT-LINE` marker 유출 | 0회여야 함 | /20 |
| G6 | 출력 길이 / 입력 길이 비율 | 4,000~5,000자 입력 기준 분포 기록 | |

> G6은 `MaxInputCharacters` 기반 경고 임계가 적절한지 판단하는 근거다.

## 8. 판정 기준

- 1절(보안)에 `FAIL`이 하나라도 있으면 **release 불가**
- P2가 `FAIL`이면 Palette를 비활성 기본값으로 두거나 기능을 보류
- G5가 0회가 아니면 marker 거부 경로를 재점검
- `판정 불가` 항목이 남아 있는 상태를 "검증 완료"로 기록하지 않는다
