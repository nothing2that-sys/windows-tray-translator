## 안전성과 오류 처리

- [ ] 선택 문자열이 없으면 원문과 클립보드를 변경하지 않는다.
- [ ] 번역 중 다른 창으로 전환하면 작성 자동 치환을 취소한다.
- [ ] 같은 창에서 다른 입력 요소로 이동하면 가능한 경우 자동 치환을 취소한다.
- [ ] API 키가 잘못됐거나 네트워크가 끊겨도 원문을 유지한다.
- [ ] 붙여넣기 대기 중 새로 복사한 클립보드 값을 덮어쓰지 않는다.
- [ ] 기존 텍스트, HTML, RTF, 이미지, 파일 목록 클립보드를 복원한다.
- [ ] 관리자 권한 프로그램에 입력하지 못하면 오류 팝업을 표시한다.

## 문자열과 화면

- [ ] 여러 줄, URL, 이모지, 특수문자가 보존된다.
- [ ] 네 가지 작성 결과 형식이 표시 예시와 일치한다.
- [ ] 긴 결과 팝업이 스크롤되며 화면 밖으로 나가지 않는다.
- [ ] 다중 모니터에서 팝업이 현재 모니터 경계 안에 표시된다.
- [ ] `Select` 팝업이 대상 입력창의 포커스를 빼앗지 않는다.
- [ ] `Select` 팝업에서 최근 언어, 숫자키, 방향키·Enter, Esc가 동작한다.
- [ ] Natural/Literal/Business와 말투 설정이 번역 결과에 반영된다.
- [ ] 용어집과 번역 제외 단어가 결과에 반영된다.
- [ ] 종료 모델 저장이 차단되고 모델 목록 새로고침이 동작한다.
- [ ] 기본 모델 실패 시 설정된 보조 모델로 번역된다.

## 설정과 실행

- [ ] 읽기·작성 단축키를 각각 바꾸면 저장 즉시 적용된다.
- [ ] 같은 단축키 또는 다른 프로그램과 충돌하는 단축키는 거부된다.
- [ ] 단축키 등록 실패 후 기존 두 단축키가 계속 동작한다.
- [ ] Windows 시작 프로그램 등록과 해제가 동작한다.
- [ ] 두 번째 실행은 즉시 종료되고 기존 트레이 프로그램은 유지된다.
- [ ] 트레이 메뉴의 종료가 단축키와 트레이 리소스를 해제한다.
