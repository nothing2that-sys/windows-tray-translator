Windows 11 · Gemini 번역 도우미

선택하고, 단축키를 누르면
바로 번역됩니다.

설치부터 API 연결, 읽기·작성 번역, 자연어 지침, 히스토리와 문제 해결까지 실제 화면과 함께 설명합니다.

읽기 Alt+R 작성 Alt+T Quick Action Ctrl+Alt+A 트레이 상주 원본 보호 번역 히스토리

1. 5분 빠른 시작

처음 사용하는 경우 아래 네 단계만 완료하면 바로 번역할 수 있습니다.

1프로그램 실행

WindowsTrayTranslator.exe를 실행합니다. 작업 표시줄 오른쪽 알림 영역에 아이콘이 생깁니다.

2Gemini API 키 저장

트레이 아이콘 우클릭 → 설정 열기 → API 탭에서 키를 입력하고 연결 테스트를 합니다.

3문장을 선택

브라우저, 메신저, 메모장 등에서 번역하려는 문장을 마우스로 드래그합니다.

4단축키 사용

Alt+R은 결과만 보여주고, Alt+T는 선택 영역을 번역문으로 바꿉니다.

가장 먼저 기억할 두 가지Alt+R = 읽기, Alt+T = 작성입니다. 단축키는 설정에서 원하는 조합으로 변경할 수 있습니다.

2. 설치와 첫 실행

실행 환경

  • Windows 11 64비트를 권장합니다. Windows 10은 Microsoft의 .NET 10 지원 대상 edition과 RC 검증 범위에서만 지원합니다.
  • 배포된 단일 EXE에는 필요한 .NET 런타임이 포함되므로 일반 사용자는 별도 설치가 필요하지 않습니다.
  • 처음 실행하면 화면에 큰 창이 뜨지 않고 알림 영역에 상주합니다.

아이콘이 보이지 않을 때

  1. 작업 표시줄 오른쪽의 숨겨진 아이콘 표시(∧)를 누릅니다.
  2. Windows Tray Translator 아이콘을 찾습니다.
  3. 자주 사용한다면 아이콘을 작업 표시줄 알림 영역으로 드래그해 고정합니다.
프로그램을 두 번 실행해도 되나요?단일 실행 방식이므로 이미 실행 중이라면 중복으로 상주하지 않습니다. 먼저 트레이 아이콘을 확인하세요.

API 키를 처음 등록하는 방법

  1. Google AI Studio에서 Gemini API 키를 준비합니다.
  2. 트레이 아이콘을 우클릭하고 설정 열기를 누릅니다.
  3. API 탭의 API 키 칸에 키를 붙여넣습니다.
  4. API 연결 테스트를 눌러 정상 응답을 확인합니다.
  5. 저장을 누릅니다. 저장된 키는 Windows 사용자 계정에 묶인 DPAPI로 보호됩니다.

4. 읽기 번역 사용법

읽기 번역은 원본 문서를 바꾸지 않고 결과를 팝업으로 확인하는 안전한 방식입니다.

  1. 번역하려는 문장을 마우스로 드래그해 선택합니다.
  2. Alt+R을 누른 뒤 키에서 손을 뗍니다.
  3. 선택 문자열을 가져오고 Gemini 번역이 끝날 때까지 기다립니다.
  4. 커서 근처의 번역 완료 팝업에서 결과를 읽습니다.
  5. 필요하면 복사를 누릅니다. 닫기 버튼 또는 설정한 시간이 지나면 팝업이 닫힙니다.
추천 설정여러 언어를 자주 읽는다면 읽기 대상 언어를 Auto로 설정하세요. 주 언어가 한국어인 문장은 영어로, 그 외 문장은 한국어로 번역합니다.

5. 작성 번역 사용법

작성 번역은 선택한 문장을 목표 언어로 번역한 다음 같은 선택 영역에 안전하게 입력합니다.

  1. 메신저나 편집기에서 직접 작성한 문장을 선택합니다.
  2. Alt+T를 누르고 키에서 손을 뗍니다.
  3. 번역 중에는 대상 창을 바꾸거나 다른 곳을 클릭하지 않습니다.
  4. 성공하면 선택 영역이 설정한 작성 결과 형식으로 교체됩니다.

작성 결과 형식

설정 화면 표시원문: 안녕하세요.용도
번역문만Hello.최종 전달 문장만 필요할 때
번역문 + 원문Hello.(안녕하세요.)상대방이 원문도 함께 봐야 할 때
원문 + 번역문안녕하세요.(Hello.)원문을 먼저 보여주고 싶을 때
줄바꿈 병기Hello.
(안녕하세요.)		긴 문장을 읽기 쉽게 병기할 때
원본 보호 동작번역 중 창이나 입력 위치가 바뀌거나 클립보드가 외부에서 변경되면 자동 입력을 취소합니다. 이때 번역 결과는 경고 팝업에 표시되며, 사용자가 직접 복사를 눌러야 클립보드에 기록됩니다.

6. Auto와 Select 언어 선택

Auto

읽기 번역 전용 자동 규칙입니다. 앱이 기술 식별자를 제외한 자연어 단어의 비중으로 주 언어를 판정하여 한국어 우세 문장은 영어로, 나머지 문장은 한국어로 번역합니다. 일부 단어나 인용구만 다른 언어인 혼합 문장도 지원합니다.

손이 가장 적게 감

Select

단축키를 누를 때마다 작은 언어 선택 팝업을 띄웁니다. 읽기와 작성 모두 사용할 수 있습니다.

매번 직접 선택
  • 숫자키 1~5로 즉시 선택할 수 있습니다.
  • ↑ ↓로 이동하고 Enter로 확정합니다.
  • Esc를 누르면 번역하지 않고 취소합니다.
  • 마지막으로 선택한 언어는 다음 팝업에서 맨 위에 (최근)으로 표시됩니다.

적용되지 않는 지시

번역 대신 질문에 답하기, 긴 설명 추가하기, 핵심 안전 규칙 무시하기처럼 번역 범위를 벗어나는 지시는 적용되지 않습니다.

선택 영역 가져오기 고급 설정

  • 최대 입력 문자 수: 한 번에 번역할 수 있는 원문의 상한입니다.
  • 복사 제한 시간: 자동 Ctrl+C 후 문자열을 기다리는 시간입니다.
  • 클립보드 복원 지연: 작성 번역을 붙여넣은 후 기존 클립보드를 복원하기 전 기다리는 시간입니다.
  • 재시도 횟수/간격: 다른 앱이 클립보드를 잠시 점유했을 때 다시 시도하는 방식입니다.
  • Ctrl+C 방식 우선: 켜면 일반 복사 방식을 먼저 사용하고, 실패 시 UI Automation을 시도합니다.
고급값은 언제 바꾸나요?일반적으로 기본값을 유지하세요. 특정 프로그램에서 선택 문자열을 자주 놓치거나 붙여넣기가 늦을 때만 제한 시간과 복원 지연을 조금씩 늘립니다.

7-3. API 탭

  • 모델 목록 새로고침: 현재 키로 사용할 수 있고 텍스트 생성을 지원하는 모델을 다시 불러옵니다.
  • API 연결 테스트: 키와 모델 조합이 정상인지 저장 전에 확인합니다.
  • 보조 모델: 기본 모델이 사용량 제한, 서버 오류, 사용 불가 상태일 때 한 번 더 시도합니다.
  • 요청 제한 시간: 지정한 시간 안에 응답이 없으면 요청을 취소합니다.
  • 일시 오류 재시도: 네트워크 또는 일시적 서버 오류에서 자동으로 다시 시도할 횟수입니다.

8. 번역 히스토리 사용법

트레이 메뉴 → 번역 히스토리에서 최근 읽기·작성 번역을 확인할 수 있습니다.

  • 최신 기록이 위에 표시되며 최대 500개를 불러옵니다.
  • 행을 선택하면 아래에서 전체 원문과 번역문을 확인할 수 있습니다.
  • 번역문 복사를 누르면 선택한 번역 결과를 다시 사용할 수 있습니다.
  • 창을 열어 둔 상태에서 새 번역을 하면 목록이 자동 갱신됩니다.
  • 일반 탭의 번역 히스토리 저장을 켠 경우에만 새 히스토리가 저장됩니다.
히스토리에는 실제 문장이 저장됩니다진단 로그에는 API 키와 문장 본문을 기록하지 않지만, 히스토리를 켜면 원문과 번역문이 %LOCALAPPDATA%\WindowsTrayTranslator\history\history-날짜.jsonl에 평문으로 저장됩니다. 민감한 문장을 다룬다면 히스토리를 끄거나 history 폴더를 삭제하세요.

9. 안전 동작과 개인정보

API 키

API 키는 설정 JSON에 평문으로 저장하지 않습니다. %LOCALAPPDATA%\WindowsTrayTranslator\secrets.dat에 Windows DPAPI CurrentUser 범위로 암호화되어 현재 Windows 사용자만 해독할 수 있습니다.

번역할 문장

선택한 문자열은 번역을 위해 Gemini API로 전송됩니다. 회사 기밀, 개인정보, 보안 정책상 외부 전송이 금지된 내용은 번역하지 마세요.

클립보드와 작성 영역 보호

  • 작성 번역 전 기존 클립보드 형식을 가능한 한 백업합니다.
  • 붙여넣기 후 기존 클립보드를 복원합니다.
  • 번역 중 활성 창 또는 포커스가 바뀌면 자동 입력을 중단합니다.
  • 외부 프로그램이 클립보드를 변경하면 사용자 데이터를 덮어쓰지 않고 작업을 취소합니다.
  • 더 높은 관리자 권한으로 실행된 앱에는 Windows 보안 정책상 입력이 차단될 수 있습니다.
민감한 환경 권장 설정히스토리가 필요하지 않다면 일반 탭의 번역 히스토리 저장을 끄세요. 이미 저장된 히스토리는 history 폴더에서 별도로 삭제해야 합니다.

10. 문제 해결

증상과 가장 가까운 항목을 펼쳐 순서대로 확인하세요.

단축키를 눌러도 아무 반응이 없습니다
  1. 트레이 메뉴의 번역 기능 활성화가 체크되어 있는지 확인합니다.
  2. 문장을 먼저 선택했는지 확인합니다.
  3. 설정에서 다른 프로그램과 겹치지 않는 단축키로 변경합니다.
  4. 대상 앱이 관리자 권한이면 WTT도 동일 권한이 필요한지 확인합니다.
  5. 로그 폴더에서 최신 translator-날짜.log를 확인합니다.
“선택된 문자열을 가져오지 못했습니다”가 나옵니다
  1. 입력 커서만 두지 말고 문자가 반전되도록 정확히 드래그합니다.
  2. 단축키를 누른 뒤 모든 키를 완전히 놓습니다.
  3. 번역 탭에서 Ctrl+C 방식 우선 사용을 켜거나 꺼 반대 순서를 시험합니다.
  4. 복사 제한 시간을 조금 늘립니다.
  5. 비밀번호 입력창, 게임, 자체 렌더링 UI는 선택 문자열 제공을 차단할 수 있습니다.
작성 번역이 선택 영역을 바꾸지 않습니다
  • 번역 중 다른 창이나 입력 위치를 클릭하면 안전을 위해 취소됩니다.
  • 대상 앱이 관리자 권한이면 일반 권한 WTT의 입력이 차단될 수 있습니다.
  • 붙여넣기 실패 시 경고 팝업의 복사를 눌러 직접 붙여넣으세요.
  • 클립보드 관리 프로그램이 동시에 내용을 바꾸고 있지 않은지 확인하세요.
API 키 또는 모델 오류가 납니다
  1. API 탭에서 키를 다시 입력하고 API 연결 테스트를 실행합니다.
  2. 모델 목록 새로고침 후 사용 가능한 모델을 선택합니다.
  3. Google AI Studio에서 키가 활성 상태이고 사용량 제한을 넘지 않았는지 확인합니다.
  4. 429 오류가 잦다면 잠시 기다리거나 보조 모델을 설정합니다.
번역이 연속으로 실패하지만 재실행하면 정상 동작합니다

현재 버전은 네트워크, 시간 초과, 서버 오류 또는 잘못된 응답이 3회 연속 발생하면 Gemini 통신 객체를 내부적으로 초기화하고 현재 번역을 한 번 자동 재시도합니다. 프로그램 전체를 종료하거나 설정·히스토리·단축키를 초기화하지 않습니다.

API 키 인증, 사용량 제한(429), 사용할 수 없는 모델, 안전 정책 및 잘못된 설정은 통신 초기화로 해결되지 않으므로 자동 초기화 대상에서 제외됩니다.

결과에 ⟦WTT-LINE-000001⟧이 보입니다

WTT-LINE은 여러 줄 원문의 줄바꿈·빈 줄·들여쓰기를 보존하기 위해 내부적으로 사용하는 임시 표식입니다. 사용자에게 보이면 안 됩니다.

현재 버전은 단일행을 포함한 모든 최종 번역 결과에서 이 표식을 제거하며, Gemini에도 원문에 없는 표식을 생성하지 않도록 지시합니다.

  1. 현재 실행 중인 앱을 완전히 종료합니다.
  2. 최신 빌드의 EXE로 다시 실행합니다.
  3. 같은 문장을 다시 번역합니다.
  4. 이전 히스토리에 이미 저장된 항목은 과거 결과이므로 그대로 남을 수 있습니다.
히스토리에 새 번역이 나타나지 않습니다
  • 일반 탭의 번역 히스토리 저장이 켜져 있는지 확인합니다.
  • 히스토리 창에서 새로고침을 누릅니다.
  • 번역이 실패한 요청은 성공 기록으로 저장되지 않습니다.
  • history 폴더 쓰기 권한과 저장 공간을 확인합니다.

11. 자주 묻는 질문

읽기와 작성의 차이가 정확히 무엇인가요?
읽기는 원본을 바꾸지 않고 팝업으로 결과만 보여줍니다. 작성은 선택한 원문을 번역 결과로 교체합니다. 처음에는 읽기로 충분히 익힌 뒤 작성을 사용하는 것이 안전합니다.
Auto와 말투 Auto는 같은 기능인가요?
아닙니다. 읽기 언어 Auto는 한국어↔영어 방향을 자동 결정합니다. 말투 Auto는 원문의 정중함이나 친근함을 유지합니다.
자연어 지침만 사용하고 고정 옵션은 무시할 수 있나요?
자연어 지침은 고정 번역 방식과 말투에 추가로 적용됩니다. 서로 충돌하지 않도록 고정 옵션을 가장 가까운 값으로 고르고, 세부 요구를 자연어 지침에 적는 방식이 가장 안정적입니다.
여러 줄 문장의 줄바꿈은 유지되나요?
가능한 한 원문의 줄바꿈, 빈 줄, 들여쓰기를 복원합니다. 모델이 내부 줄 표식을 잘못 처리하면 표식을 제거한 안전한 결과를 사용하므로 일부 줄 배치가 단순화될 수 있습니다.
번역 결과가 마음에 들지 않으면 어떻게 하나요?
번역 방식을 Natural/Literal/Business 중 바꾸고, 말투와 자연어 지침을 구체화하세요. 반복되는 전문 용어는 사용자 용어집에 원문=번역문 형식으로 등록하는 것이 효과적입니다.
회사에서 사용해도 되나요?
기술적으로 사용할 수 있지만 선택 문자열이 Gemini API로 전송됩니다. 회사의 외부 AI 사용 정책, 개인정보 처리 규정, 비밀정보 반출 규칙을 먼저 확인하세요.
